# API reference\n\nBase URL `http://localhost:8000`; Swagger UI `/docs`.\n\n| Method | Path | Purpose |\n|---|---|---|\n| GET | `/health` | API and Hindsight status |\n| GET | `/incidents` | List incidents |\n| GET | `/machines/{machine_id}` | Machine history |\n| POST | `/incidents` | Create incident and attempt retain |\n| POST | `/investigate` | Recall and generate advisory brief |\n| POST | `/outcomes` | Save follow-up and attempt retain |\n| POST | `/demo/seed` | Load fictional data |\n\nExample: `{"machine_id":"M-017","symptom":"Vibration after warm-up","operating_condition":"Heavy load","operating_duration_minutes":40,"use_memory":true}`.
