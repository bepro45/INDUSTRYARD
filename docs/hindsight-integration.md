# Hindsight integration\n\nConfigure `HINDSIGHT_BASE_URL`, `HINDSIGHT_API_KEY`, and `HINDSIGHT_BANK_ID` in `backend/.env`. The adapter uses the official Python SDK methods `Hindsight(...)`, `create_bank(...)`, `retain(...)`, and `recall(...)`. Official guide: https://docs.hindsight.vectorize.io/cloud/python-sdk/. Verify `GET /health`, seed the sample data, then inspect `hindsight_available` and `memories` from `/investigate`. If unavailable, the API says so; SQLite results must not be described as Hindsight recall. No authentication or tenant isolation is implemented; use synthetic data only.
