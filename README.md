## 👋 About the Project

Workplace safety is one of the most important aspects of every industry. Even a small unsafe condition or near-miss incident can lead to a serious accident if it goes unnoticed.

**INDUSTRYARD** is an AI-assisted industrial safety management platform designed to make workplace safety smarter, simpler, and more accessible through technology.

The project combines a modern web interface, backend services, and AI-assisted capabilities to support workplace safety activities and safety-related information.

**Our mission is simple: Make workplaces safer through smarter technology.**

## ✨ Key Features

- **Industrial Safety Management:** Supports digital workplace safety activities.
- **Near-Miss Awareness:** Helps focus on potential risks before they lead to accidents.
- **AI-Assisted Capabilities:** Integrates AI to support safety-related information and analysis.
- **Interactive Dashboard:** Provides a user-friendly interface for accessing application features.
- **Backend Integration:** Connects the frontend with backend services.
- **Web-Based Platform:** Access the deployed application through a browser.

## 🚀 How to Run Locally

**Prerequisites:** Python, Node.js, npm and Git.

### 1. Clone the Repository

```bash
git clone https://github.com/bepro45/INDUSTRYARD.git
cd INDUSTRYARD
```

### 2. Start the Backend

```bash
cd backend
python -m venv .venv
source .venv/bin/activate   # On Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

The backend runs at: <http://127.0.0.1:8000>

### 3. Start the Frontend

Open a new terminal window, then run:

```bash
cd frontend
npm install
npm run dev
```

Open the local URL displayed in your terminal (usually <http://localhost:5173>).
