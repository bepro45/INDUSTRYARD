## 👋 Introduction

Workplace safety is one of the most important aspects of any industry. Even a small unsafe condition or a near-miss incident can become a serious accident if it goes unnoticed.

**INDUSTRIYARD** is developed with the goal of making industrial safety management smarter and more accessible through technology.

It combines a modern web interface, backend services, and AI-assisted capabilities to support workplace safety activities, identify potential risks, and improve the way safety-related information is managed.

The idea is simple: **make workplaces safer through smarter technology.**

## ✨ Main Features

- **Industrial Safety Management:** Supports digital safety-related activities and workflows.
- **Near-Miss Awareness:** Focuses on identifying and understanding incidents that could lead to workplace accidents.
- **AI-Assisted Capabilities:** Uses AI integrations to support safety-related information and analysis.
- **User-Friendly Interface:** Provides a simple web-based experience for accessing project functionality.
- **Backend Integration:** Connects the frontend with backend services for application operations.

## 🚀 Run the Project Locally

**1. Clone the repository**

```bash
git clone https://github.com/bepro45/INDUSTRIYARD.git
cd INDUSTRIYARD
```

**2. Start the backend**

```bash
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Backend runs at: `http://127.0.0.1:8000`

**3. Start the frontend**

Open a new terminal:

```bash
cd INDUSTRIYARD/frontend
npm install
npm run dev
```

Open the local URL shown in your terminal.

**Requirements:** Python, Node.js, npm and Git.
